# Use extracted findings

Recommend a next destination only when it helps the user's task:

- A durable reference note for stable technical or project facts.
- A task tracker for accepted actions, retaining owner, deadline and source.
- A decision log for adopted choices and their conditions.
- A reply or report drafted from the confirmed extraction.
- No follow-up when the requested extraction is the complete deliverable.

Use the user's established destination and available tools. No named knowledge-base, transcript-fetching or messaging skill is required. If another workflow supplied a taxonomy, return the evidence in that taxonomy so the caller can use it directly.

Do not automatically send messages, publish, assign work, add tasks or change shared documents. Existing authorization for those actions remains valid; carry out requested follow-up within that scope rather than inventing another mandatory confirmation step.
